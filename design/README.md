# 디자인 시안 (2026-10-27)

웹 버전 디자인을 정하려고 만든 시안 세 개예요. 2026년 웹 앱 디자인 흐름(Linear·Vercel의 어두운 화면과 벤토 격자, Vercel·Gumroad의 구조적 스타일, iOS 26의 리퀴드 글래스와 Perplexity식 가운데 입력창)을 참고했어요.

| 시안 | 방향 |
| --- | --- |
| `concept_a_dark.png` | 어두운 화면, 돌아가는 레이더가 위반 표현을 잡아냄, 결과는 벤토 격자 |
| `concept_b_structural.png` | 굵은 선과 큰 글씨, 형광펜 노랑과 빨간 스탬프 |
| `concept_c_glass.png` | 파스텔 배경 위 반투명 유리, 가운데 긴 입력창 |

최종: C(유리·가운데 입력창)를 바탕으로 A의 레이더를 밝은 유리 버전으로 합쳤어요. 레이더 바늘이 지나갈 때 실제 검사 결과가 하나씩 잡혀요.
