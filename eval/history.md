## v1 → v2에서 바꾼 것 (개발 세트에서 놓친 문구 24개를 유형별로 묶어 해결)

1. **시술처럼 보이는 표현**: 피부 속 침투·주입, 흡수율 극대화 (식약처 적발 2025·2026.2)
2. **약처럼 보이는 표현 추가**: 모낭충, 질염, 땀 억제, 속눈썹·모발이 자람, 이뇨, 호르몬, 반흔, 갱년기, 통증 (KCIA 해설서)
3. **먹을 수 있다는 화장품 표현** (KCIA 해설서 24쪽)
4. **일반 화장품의 기능성 표현 추가**: 안티링클, 자외선 차단, 탈모·여드름성 피부·튼살·가려움 완화 (KCIA 해설서 15~23쪽)
5. **식품의 다이어트·비만약 표현**: 식욕억제, 지방 차단·배출, 단기간 감량, 위고비·마운자로 (식약처 적발 2026.7)
6. **식품의 신체 효능 표현**: 피부 탄력, 붓기 관리, 저속노화, ‘○○에 좋은’ (식약처 적발 2025·2026.5·6)
7. **오탐 수정**: ‘식물줄기세포 함유’는 허용 (KCIA 해설서 26~27쪽)
8. **조건부 표현 알림**: 알레르기 테스트, 일시적 셀룰라이트 감소, ‘2주 경과 후’

한국어 정규식에서 겪은 문제도 있었어요. ‘자라’로는 ‘자란다’가 잡히지 않아요. ‘란’이 ‘라+ㄴ’이 합쳐진 한 글자라서, 어미가 붙은 형태(자란·자랍)를 따로 넣었어요.

## v2 시험 세트에서 놓친 것 → v3에서 해결

시험 세트를 보고 고쳤기 때문에, v3 점수는 새로 모은 시험2 세트로 다시 쟀어요.

- 스테로이드 ‘성분 없음’ 형태, 가슴 확대, 체형 변화, 체내 노폐물, 심신 피로 회복, ‘의사가 공동개발’ (화장품)
- 혈당 관리, 비염, 코막힘 감기, 체험기 ‘피부가 좋아졌습니다’ (식품)
- 조건부: 항균(세정용만 가능), 피부장벽 손상 개선

v3에서 추가한 것: 스테로이드 ‘성분 없음’·無(무) 표기·벤조피렌, 가슴 확대·체형 변화·체내 노폐물·피로 회복(화장품), ‘공동개발’, 혈당·혈압·콜레스테롤 ‘관리’, 감기·비염·코막힘·기침·가래(식품), ‘~가 좋아졌어요’ 형태의 후기, 조건부 알림(항균, 피부장벽).

## 시험2에서 알게 된 것

- **첫 시험 세트 점수(79.7%)는 낙관적이었어요.** v2는 새로 모은 문구에서 48.1%였어요. 첫 시험 세트는 개발 세트와 같은 보도·해설서에서 나눈 것이라 문구 스타일이 비슷했기 때문이에요. 시험 세트는 다른 시기·다른 출처에서 따로 모아야 한다는 걸 확인했어요.
- **v3는 시험2에서 59.3%예요** (화장품 83.3%, 식품 40.0%). 오탐은 계속 0이에요.
- **규칙 기반의 한계가 보여요.** 놓친 11개 중 상당수가 ‘붓기차’, ‘철분약’, ‘한약’처럼 단어를 붙여 만든 이름이거나, ‘마신 날은 좀 덜 피로한 것 같아요’, ‘제품을 먹고 키가 컸다’처럼 문맥으로 판단해야 하는 후기예요. 단어 목록을 늘리는 것보다 AI 검토로 보완하는 게 맞는 영역이에요.
- 한계: 시험2도 규칙을 만든 사람이 직접 모았어요. 문구 선택에 편향이 있을 수 있어요.

### 알게 된 것

- **짧은 문구 하나씩 판단하는 일은 그냥 AI도 매우 잘해요.** 위반 탐지 100%, 오탐 0%로 규칙만(59%)보다 훨씬 나아요. "규칙이 AI보다 잘 찾는다"는 차별점이 될 수 없어요.
- **그냥 AI는 건강기능식품 인정 문구를 모두 "허용"이라고만 했어요.** 이 문구들은 해당 원료가 실제로 그 기능성을 인정받았는지, 광고 자율심의를 받았는지 확인해야 쓸 수 있어요. 셀러가 꼭 확인해야 할 절차를 알려주지 않은 거예요.
- **처벌 정보는 그냥 AI가 25개 중 3개를 틀렸어요.** ‘긴장완화’, ‘붓기차’, ‘눈에 좋은’을 건강기능식품 오인(최대 징역 10년)으로 봤는데, 식약처는 거짓·과장(최대 징역 5년)으로 분류했어요. 기준표를 준 C는 1개만 틀렸어요.
- **대안 문구는 물을 때마다 달라졌고(같은 경우 15%), 2개는 ‘한방 원료’처럼 또 걸리는 표현이었어요.**
- 한계: 그냥 AI 역할은 가장 강한 AI 모델에 전문가처럼 정리된 질문을 준 경우라, 실제 셀러가 무료 AI에 대충 묻는 것보다 유리한 조건이에요. 문구 수(위반 27개)도 적고, 짧은 문구 단위라 긴 상세페이지 전체나 이미지에서의 차이는 아직 재지 않았어요. ‘긴장완화’ 등 3개의 처벌 정답은 보도자료의 유형 분류를 따랐어요.

## 이미지 상세페이지 실험 (2026-10-26)

실제 상세페이지처럼 세로로 긴 가상 이미지 3장(화장품·일반 식품·건강기능식품, 860×2,163~2,649px)을 만들었어요. 위반 문장 17개, 자료가 필요한 문장 2개, 평범한 문장 16개를 섞었어요. 이미지·정답표·답·채점은 `eval/page_test/`에 있어요.

| | 그냥 AI (이미지 통째로) | 규칙만 (AI가 옮겨 적은 글) | 규칙 + 기준표 AI |
| --- | --- | --- | --- |
| 위반 문장 찾음 | 17/17 | 14/17 | 17/17 |
| 자료 필요 문장 알림 | 1/2 | 2/2 | 2/2 |
| 평범한 문장을 위반으로 판정 | 0/16 | 0/16 | 0/16 |
| 평범한 문장에 확인 요청 | 4/16 | 0/16 | 0/16 |

- **AI의 이미지 글자 읽기는 정확했어요.** 세 장의 글자를 하나도 틀리지 않고 옮겼어요.
- **긴 이미지라서 그냥 AI가 놓치는 일은 이번엔 없었어요.** ‘긴 페이지에서는 그냥 AI가 놓친다’는 가설은 맞지 않았어요. 다만 글꼴이 깔끔하고 길이가 실제(보통 1만 px 이상)보다 짧은 가상 이미지였어요.
- **그냥 AI는 이번에도 건강기능식품 인정 문구(혈행 개선)에 확인 절차를 알려주지 않았어요.** 짧은 문구 실험(0/5)과 같은 패턴이에요.
- 그냥 AI의 확인 요청 4개 중 ‘노폐물 정돈’은 해설서상 허용 표현이에요. ‘원산지 확인’, ‘심의필 확인’은 오히려 쓸모 있는 지적이었어요.
- 규칙만으로는 ‘전문의가 **직접** 개발’, ‘심혈관 **질환** 예방’, ‘치매 예방’을 놓쳤어요. 기준표 AI는 ‘스테로이드 성분 무첨가’와 ‘혈행 개선’을 놓쳤는데, 규칙이 잡아서 합치면 모두 찾았어요. 규칙과 AI가 서로 빈 곳을 메웠어요.
- 한계: 페이지와 정답을 같은 사람이 만들었고, 문장 수도 적어요.

## 규칙 v3.1 (2026-10-26)

이미지 상세페이지 실험에서 규칙이 놓친 세 표현을 보완했어요: ‘전문의가 **직접** 개발’, ‘○○ **질환** 예방’, ‘치매’. 이 세 문장은 이제 개발용으로 쓴 셈이라, 이미지 실험 점수는 v3 기준(14/17)으로 남겨 둬요. 기존 평가 세트 점수는 변하지 않았어요(시험2 59.3%, 오탐 0%).

## 단속 데이터 분석 → 규칙 v3.2 (2026-10-27)

식약처 점검 발표 25건(2021.10~2026.7), 연도별 집계, 보도에 인용된 실제 적발 문구를 모아 분석했어요(`data/enforcement/`, `analysis/enforcement.py`, 결과 `analysis/out/report.md`).

- 식품 온라인 적발: 2024년 10,033건 → 2025년 14,254건(+42.1%). 2025년의 50.8%가 건강기능식품 오인, 25.3%가 질병 예방·치료.
- 화장품: 2021~2025.9 누적 12,617건 중 69.2%가 의약품 오인.
- 점검 주제는 계절을 따라가요(수능 → 수험생 영양제, 환절기 → 감기·비염, 휴가철 → 다이어트).

이번에 처음 모은 실제 적발 문구 23개를 분석 전 규칙(v3.1)에 돌렸더니 **16개(69.6%)**만 잡았어요. 이 숫자가 규칙이 처음 보는 최신 문구에 대한 성적이에요. 놓친 7개(집중력 강화, 두뇌 건강, 키 성장, ‘전 피로에 더 좋았어요’, 지방세포 증식, 모발성장촉진, ‘11살은 어려집니다’)를 보고 기존 규칙 5개를 넓혀 v3.2를 만들었어요(규칙 수는 37개 그대로). 이 23개는 이제 개발용으로 쓴 셈이에요.

고정해 둔 시험 세트는 손대지 않았어요: 시험2 59.3%(변화 없음), 전체 오탐 0%. 시험2에서 놓친 11개는 일부러 규칙에 넣지 않았어요(넣으면 시험 점수가 의미를 잃어요).

## 무료 글자 읽기(Tesseract) 실험 (2026-10-27)

API 사용료 없이 이미지 상세페이지를 읽을 수 있는지 재 봤어요. 같은 문장 35개(위반 17·자료 필요 2·평범 16)를 두 가지 모양으로 그렸어요.
- 쉬운 페이지: 기존 이미지 실험의 3장(세로 2,163~2,649px, 깔끔한 글씨)
- 어려운 페이지: 같은 문장을 실제 상세페이지처럼 그린 3장(세로 7,643~9,529px, 사진 같은 배경 위 글씨, 얇은 글꼴, 외곽선·그림자, 기울인 글씨, 작은 연회색 글씨) — `tools/build_pages_hard.py`

채점은 `eval/page_test/score_free.py`. 정답 문장마다 읽은 글에서 가장 비슷한 줄을 찾아 글자 일치율을 재고, 그 줄을 규칙으로 검사해 원문을 검사했을 때와 비교했어요.

| | 쉬운 페이지 | 어려운 페이지 |
| --- | --- | --- |
| 평균 글자 정확도 | 92.0% | 67.3% |
| 거의 그대로 읽은 문장 (95% 이상) | 26/35 | 15/35 |
| 원문이면 규칙이 잡는 문장 중 읽은 글로도 잡은 것 | 15/19 | 13/19 |
| 잘못 읽어서 새로 걸린 평범한 문장 | 0 | 0 |
